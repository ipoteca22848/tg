# DEMO bot

Отдельный Telegram-бот, не модификация серверов Telegram. Python 3.11+,
внешние Python-пакеты не нужны. Все номера вымышленные с префиксом DEMO;
балансы звёзд и TON — записи в локальной SQLite, без реальной стоимости.
Нет SMS, кодов подтверждения, регистрации Telegram, покупки и переводов.

Создать бота через @BotFather. Токен безопасно передать в окружение
`TELEGRAM_BOT_TOKEN`, числовой Telegram ID владельца @b4hra1n — в
`DEMO_ADMIN_ID`. Username не используется для авторизации, поскольку он
изменяемый. Без этих параметров запуск останавливается. Токен не присылать
в чат и не сохранять в Git. При первом запуске не использовать бота,
который уже обслуживается другим процессом или webhook.

Запуск из корня репозитория:

```console
python demo_bot/bot.py
```

Для реального запуска требуется HTTPS-доступ к `api.telegram.org`.
Токен включён в путь Bot API: инфраструктура должна поддерживать обычный
токен BotFather, подстановку proxy placeholder в пути не предполагаем.
В этой среде токена и admin ID пока нет; подключение к Telegram не проверено.

В личном чате: `/start`, `/id`, `/number`, `/balance`.
Команда `/number +7` выдаёт новый демономер с `+7`, `/number +888` — с `+888`.
Можно задать любой префикс из 1–3 цифр, начиная с 1–9. `/prefixes` показывает
примеры. Это визуальные форматы: длины и коды не являются справочником
национальных планов нумерации. `/number` без параметров сохраняет текущий номер.
Администратор получает бесконечные **тестовые** балансы и команды:

```text
/admin
/setnumber 123456789 +79990000000
/setnumber 123456789 любой-вымышленный-номер
/grant 123456789 stars infinite
/grant 123456789 ton 12.5
/users
```

Даже если метка похожа на настоящий телефон, выдаётся `DEMO:+79990000000`:
этот номер не предоставляется пользователю и не принимает SMS. Одинаковые
метки допустимы — это симуляция, не распределение настоящих телефонных номеров.
Права администратора действуют только внутри этого демобота.

SQLite сохраняет участников, номера, балансы и offset. Запускать один процесс
на один токен/базу. При недоставленном ответе команда может быть уже применена;
пользователь может повторить её — команды назначения идемпотентны. Хранить
базу приватно; в Git она исключена.
