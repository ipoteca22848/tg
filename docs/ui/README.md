# Cohesive generated icon family

`icons-atlas.png` is a generated transparent PNG containing a 4×4 monoline lavender icon family. `icons.css` and `src/icons.js` address each icon as a CSS sprite. No icon font or Unicode character is used for these images.

Rows, left to right:
1. Chat, bookmark, gift, wallet.
2. Archive, settings, airplane, people.
3. Star, crystal, infinity loop, smile.
4. Moon, sun, lock, edit.

Small utility controls (back, close, copy, search, etc.) use explicit SVG paths of matching stroke weight and color. Personal messages and the emoji picker continue to support ordinary emoji as message content.
